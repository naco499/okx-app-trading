### Buy、Convert 和现货交易有什么区别？

这三个入口看起来相似，实际用途不同。

**Buy** 更适合买入数字资产。你选择现金币种、资产和支付方式，系统根据当前报价完成订单。

**Convert** 是资产之间的快速兑换。它通常不需要你自己设置订单簿价格，操作步骤比较短，但最终应查看报价细节、滑点和到账数量。

**Spot trading** 是标准现货交易。你可以选择交易对、订单类型和价格，成交取决于订单簿和当时的市场流动性。想控制买入价格的人，通常会更关注限价单；想尽快成交的人，可能会选择市价单，但最终成交价可能随市场变化。

如果只是第一次买入少量资产，Buy 流程更容易理解。如果你已经知道交易对、价格和订单类型，现货交易界面提供的控制会更多。

## OKX App 支持定投吗？

OKX App 提供 recurring buy，也就是定期买入功能。官方说明，用户可以设置每日、每周、每月两次或每月执行的购买计划，并选择使用账户余额或其他可用支付方式。

设置定投时通常需要选择：

- 购买的数字资产
- 每次投入的现金金额
- 执行频率
- 支付来源
- 开始时间

需要注意的是，定投不是锁定收益的工具。它只是按照设定时间执行买入，资产价格仍会波动。如果账户余额不足，订单可能失败；如果连续多次执行失败，计划还可能被自动暂停。官方帮助页面也建议用户在每次执行前确保账户中有足够余额。

对于不想每天盯着行情、但希望定期投入固定金额的人，定投功能比较方便。对于需要精确控制入场价的人，限价单可能更合适。

### 现货交易

现货交易是最基础的交易模式。买入后，资产通常会进入对应账户余额；卖出后，所得资产会根据交易规则进入账户。现货交易本身不等于杠杆交易，不会因为仓位变化产生强平风险，但资产价格下跌仍然可能造成损失。

交易机器人可以帮助用户执行预设策略，例如网格或定投。机器人不会自动判断某项资产“必然上涨”，它只是根据你设置的参数执行规则。

使用机器人前，至少应该看清楚：

- 投入金额
- 价格区间
- 网格数量
- 触发条件
- 预计收益计算方式
- 终止和暂停规则
- 手续费是否单独计算

设置参数时不要只看预估收益。市场一旦脱离机器人适合的价格区间，策略表现可能和页面上的模拟结果完全不同。

### 挂单和吃单是什么意思？

**挂单，也就是 Maker**，通常指订单没有立即成交，而是先进入订单簿等待其他订单匹配。

**吃单，也就是 Taker**，通常指订单立即和订单簿中已有订单成交。

同一账户、同一交易对下，吃单费率通常会高于挂单费率。实际下单时，App 的订单确认页面和 Fee rules 页面会显示当前交易对适用的具体费率。OKX 官方建议用户登录 App 后，在 Trade 中查看对应交易对的 Fee rules。
